# 🚀 Ultimate Android Learning Journey (Core & Compose)

Welcome to my master Android development repository! This project is a comprehensive playground where I am building and tracking my skills from the absolute basics of **Jetpack Compose** to core **Android Jetpack Architecture, System Components, and Data Storage**.

---

## 📌 Roadmap & Progress Tracker

### 🗺️ Phase 1: Jetpack Compose Fundamentals (UI)
* [ ] **Text & Typography** - `Text`, `Clickable Text`, `Selectable Text`
* [ ] **Input Fields** - `TextField`, `Outlined TextField`, `Basic TextField`
* [ ] **Layouts & Structures** - `Column`, `Row`, `Box`, `Spacer`, and `ConstraintLayout`
* [ ] **Buttons & Interactive Components** - `Button`, `OutlinedButton`, `TextButton`, `IconButton`
* [ ] **Modifiers** - Mastering layouts, sizing, padding, and gestures using `Modifier`
* [ ] **Images & Visuals** - `Image`, `Icon`, `Card`, and `Divider`
* [ ] **Scaffolding** - Implementing `Scaffold` with `Top Bar`, `Bottom Bar`, and `FAB`

### 🔄 Phase 2: State Management & Navigation
* [ ] **State Holders** - Reactive UI updates using `mutableStateOf` and `remember`
* [ ] **State Hoisting** - Making composables stateless and reusable by moving state up
* [ ] **Compose Navigation** - Setting up `NavController`, `NavHost`, and passing arguments between screens
* [ ] **ViewModel Integration** - Holding UI-related data with lifecycle awareness

### ⚙️ Phase 3: Core Android Components & Lifecycle
* [ ] **Activity Lifecycle** - Understanding and logging all lifecycle states (`onCreate`, `onStart`, `onResume`, etc.)
* [ ] **App Components** - Deep dive into Android core pillars (Activities, Services, Broadcast Receivers, Content Providers)
* [ ] **Intents & Communication** - Explicit and Implicit Intents for navigating and sharing data between apps

### 💾 Phase 4: Data Storage & Database Architecture
* [ ] **Shared Preferences** - Saving small key-value pairs for app settings/sessions
* [ ] **Internal Storage** - Saving private app data directly on the device internal filesystem
* [ ] **External Storage** - Handling public asset streams and shared media directories
* [ ] **Room Database** - Implementing Local caching, SQLite CRUD operations, Entities, and DAOs
